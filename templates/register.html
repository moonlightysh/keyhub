📝 注册账号 & 上传 GPG 公钥

上传你的邮箱、昵称和 GPG 公钥（ASCII Armor 格式，即以 -----BEGIN PGP PUBLIC KEY BLOCK----- 开头的文本）。 其他用户就能在“用户列表”里选择你，发送只有你用私钥才能解开的加密邮件。

这既是你的登录标识，也是他人向你发送加密邮件的收件人地址。
如何导出：gpg --armor --export 你的邮箱，然后把整段输出粘贴到这里。 只接受公钥，不要上传私钥！

🤔 还没有 GPG 密钥对？两分钟生成一对：

  1. 安装 GPG：
    • macOS：brew install gnupg，或下载 GPG Suite
    • Windows：下载 Gpg4win
    • Linux (Debian/Ubuntu)：sudo apt install gnupg
  2. 生成密钥对（带你的邮箱）：
    gpg --full-generate-key，一路默认即可，注意设置一个强口令保护私钥。
  3. 导出公钥：
    gpg --armor --export you@example.com > my_public_key.asc， 然后把 my_public_key.asc 里的内容复制到上面的文本框即可。
